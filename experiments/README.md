# Second Sun Experiments

This directory preserves visual studies that informed the maintained
[`Heliogenesis`](../integrations/web/heliogenesis/README.md) browser integration. They are design provenance and an
unconstrained laboratory, not supported integration surfaces.

| Study | Status | Purpose |
| --- | --- | --- |
| [`second-sun.html`](second-sun.html) | Frozen baseline | Dependency-free reference for the original event. |
| [`heliogenesis-lab.html`](heliogenesis-lab.html) | Active laboratory | Three.js staging ground for new treatments. |
| [`archive/second-sun-d3.html`](archive/second-sun-d3.html) | Archived study | Earlier particle-cloud study. |

Only Heliogenesis is packaged and covered by browser CI. Experiments may use remote development dependencies, need a
local HTTP server, or intentionally diverge from the integration API. A successful visual idea should be adapted into
Heliogenesis deliberately rather than synchronizing either implementation wholesale.
