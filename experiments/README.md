# Second Sun Experiments

This directory preserves visual studies that informed the maintained browser integrations. They are design provenance
and an unconstrained laboratory, not supported integration surfaces.

| Study | Status | Purpose |
| --- | --- | --- |
| [`second-sun.html`](second-sun.html) | Frozen baseline | Dependency-free reference for the original event. |
| [`heliogenesis-lab.html`](heliogenesis-lab.html) | Active laboratory | Three.js staging ground for new treatments. |
| [Looks Back](the-document-looks-back.html) | Active laboratory | The Document Looks Back staging ground. |
| [`archive/second-sun-d3.html`](archive/second-sun-d3.html) | Archived study | Earlier particle-cloud study. |

Experiments may use remote development dependencies, need a local HTTP server, or intentionally diverge from an
integration API. A successful visual idea should be adapted into its maintained integration deliberately rather than
synchronizing either implementation wholesale.
